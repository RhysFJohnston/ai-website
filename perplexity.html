Perplexity | Perplexity AI

Perplexity is a 'retrieval-augmented generation' model. This means that before answering with the information it currently has, it will search the live web and read over several articles and pieces of relevant information. It will then absorb and compress this info into key notes and use them to answer the user's question more accurtately. It is best for web search queries because this feature allows it to prioritize factual accuracy and modern information over flowery answers and creativity. Its info is always up-to-date.
